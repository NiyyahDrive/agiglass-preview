# AGI Glass — cinematic concept preview

Marker: `AGI_GLASS_CINEMATIC_PREVIEW_20260917`

Public concept preview for AGI Glass (auto glass, Shkodër, Albania). This is not the official AGI Glass website (agiglass.al).

Live preview: https://niyyahdrive.github.io/agiglass-preview/

The page carries `<meta name="robots" content="noindex, nofollow, noarchive, nosnippet">` and a visible concept banner. Noindex only asks search engines not to index the page; it is **not** access control. Anyone with the URL can open it.

## Technologies

- Static HTML (Albanian, `lang="sq"`)
- Hand-written CSS, mobile-first
- Vanilla JavaScript, no dependencies or trackers
- WebP/JPG images and MP4 video
- GitHub Pages hosting

## Source material and truthfulness

- Images and video come from AGI Glass's own business video.
- Business details (phone, address, opening hours, email, services, founding year) are taken from the official AGI Glass website.
- Phone (`tel:`) and Google Maps links lead to the real business. Calling or following a route contacts AGI Glass itself, not the preview's author.
- Deliberately not included: customer quotes, ratings, partner logos, certifications, prices, WhatsApp, social links.
- The contact form is disabled and sends nothing.
- Albanian copy has not been proofread by a native speaker.
